# 紫微命盤 ‧ 八字 ‧ 流年 — 設計規格

- 日期:2026-05-19
- 專案代號:ziwei-destiny
- 交付物:單一檔案 `ziwei-destiny.html`

## 1. 目標

提供一個網頁應用,使用者輸入姓名、性別與出生時間後,得到:

1. 紫微斗數命盤(十二宮、十四主星)
2. 八字四柱與八字重量(袁天罡稱骨)
3. 詳細解盤:整體格局與十二宮逐宮詳解
4. 2026 丙午年流年詳細論斷

畫面風格為「星空墨韻」— 深夜藍黑漸層 × 星金,水墨留白,沉靜神祕。

## 2. 範圍與非目標

**範圍內**

- 國曆 / 農曆雙向輸入
- 1900–2100 出生年份
- 本地確定性計算:萬年曆換算、八字四柱、稱骨重量、紫微骨架(命宮/身宮、五行局、十四主星落宮)
- Gemini API 生成文字解讀,分四段
- 列印 / 存 PDF、另起一盤

**非目標**

- 不做真太陽時 / 出生地經度校正
- 不做後端伺服器、不做多人部署、不做帳號系統
- 不做流年以外年份的詳細論斷(僅 2026)
- 本地不精算四化、六吉六煞、雜曜、大限小限 — 交由 Gemini 解讀層處理

## 3. 核心架構決策

| 決策 | 結論 | 理由 |
|---|---|---|
| 排盤計算 | 骨架本地精算 + 其餘 Gemini | 星曜落宮為確定性演算法,LLM 會幻覺;骨架本地算可確保盤面正確 |
| 應用形式 | 單一 HTML 檔 | 免安裝,雙擊即開 |
| Gemini 金鑰 | 執行時輸入,「記住金鑰」勾選(預設不勾) | 金鑰只存使用者瀏覽器,只送 Google API |
| 內容生成 | 方案 A:分段漸進生成 | 命盤秒出、逐段揭曉有儀式感、容錯佳 |
| 視覺風格 | 星空墨韻 | 使用者自三方案中選定 |
| 流年範圍 | 僅 2026 丙午年詳細論斷 | — |
| 解盤組織 | 十二宮逐宮詳解 | 對應「越詳細越好」 |

## 4. 檔案與模組

單一檔案 `ziwei-destiny.html`,內嵌 HTML / CSS / JavaScript,不依賴外部函式庫。唯一執行期外部相依為 Gemini API。內部邏輯模組:

| 模組 | 職責 | 相依 |
|---|---|---|
| 萬年曆模組 | 1900–2100 農曆 `lunarInfo` 資料表 + 24 節氣表;國曆↔農曆換算、閏月判斷、節氣查詢 | 無 |
| 八字模組 | 由出生時間推年/月/日/時四柱干支 | 萬年曆模組 |
| 稱骨模組 | 四柱對應袁天罡稱骨表權重加總,輸出總重與歌訣 | 八字模組 |
| 紫微模組 | 命宮/身宮、五行局、紫微星定位、十四主星落十二宮 | 萬年曆模組 |
| Gemini 模組 | 封裝 `streamGenerateContent` 呼叫、串流接收、金鑰管理 | localStorage |
| 畫面渲染 | 表單、十二宮格、解讀面板、流年面板 | 全部 |
| 流程控制 | 串接 輸入→本地排盤→分段呼叫 Gemini→逐段顯示 | 全部 |

## 5. 本地計算引擎(確定性)

### 5.1 萬年曆模組

- 內建標準 `lunarInfo` 整數陣列(1900–2100)與 24 節氣資料表。
- 提供:`solarToLunar`、`lunarToSolar`、`isLeapMonth`、`getSolarTerm`。

### 5.2 八字模組

- 日柱:由儒略日推算干支,純公式,精確。
- 時柱:由日干 + 時辰推,純公式。
- 年柱:以**立春**為界(非元旦),查節氣表。
- 月柱:以**節**(12 主節)為界,查節氣表,正確處理交界。

### 5.3 稱骨模組

- 年/月/日/時四柱各對應袁天罡稱骨表固定「兩錢」權重。
- 加總得總重(例:三兩六錢),附對應歌訣原文。

### 5.4 紫微模組(骨架)

1. 由農曆月 + 出生時辰定命宮、身宮地支。
2. 由命宮干支納音定五行局(水二 / 木三 / 金四 / 土五 / 火六局)。
3. 由五行局 + 農曆日定紫微星落宮。
4. 紫微定位後,天府星系與十四主星依固定規則順 / 逆推落十二宮。
5. 十二宮貼宮名(命、兄弟、夫妻、子女、財帛、疾厄、遷移、僕役、官祿、田宅、福德、父母)。

## 6. Gemini 整合

### 6.1 模型與呼叫

- 端點:`streamGenerateContent`(串流,文字逐字浮現)。
- 預設模型 `gemini-2.5-flash`;設定欄可切換 `gemini-2.5-pro`。
- 金鑰:啟動時輸入欄;「記住金鑰」勾選決定是否存 localStorage(預設不勾)。

### 6.2 四段獨立呼叫(依序)

1. 整體格局與命主性情
2. 十二宮逐宮詳解(最長,內部逐宮 / 分批呼叫,確保每宮詳盡)
3. 八字重量論斷(稱骨歌訣白話化 + 結合四柱論一生格局)
4. 2026 丙午年流年(流年四化、事業/財運/感情/健康、月份走勢)

### 6.3 事實鎖定

每段 prompt 含「事實鎖定」區,把本地算好的命盤骨架、八字四柱、稱骨結果以不可更動的事實陳述帶入,明確指示 Gemini 只做解讀、不得重排星曜。此為控制 LLM 幻覺的關鍵。

### 6.4 用詞分寸

- 以「傳統命理觀點」「僅供參考」口吻呈現。
- 健康、壽元等敏感面向採正向、建設性措辭。
- 頁尾固定免責聲明:命理內容僅供娛樂與參考,不構成醫療、財務或人生決策建議。

## 7. 畫面與流程(星空墨韻)

單頁三幕,垂直捲動,每幕淡入 + 星塵微動。

- **第一幕 ‧ 入命**:星空背景、置中標題「紫微斗數」、輸入卡(姓名/稱謂、性別、國曆/農曆切換生日、時辰下拉、鎏金「起盤」按鈕);無金鑰時先顯示金鑰欄(含「記住金鑰」勾選)。
- **第二幕 ‧ 命盤**:按「起盤」後本地引擎瞬間排盤,十二宮 4×4 格線淡入(中宮顯示命主、生辰、五行局),各宮列主星與骨架星曜。下方依序浮現四個解讀面板,文字串流顯示,生成中顯示星點 loading,失敗顯示「重新揭示」按鈕。
- **第三幕 ‧ 流年**:2026 丙午年面板,外框流光強調,含事業/財運/感情/健康分項與月份走勢。
- **收尾**:頁尾免責聲明;「另起一盤」重置;「列印 / 存 PDF」(瀏覽器列印,套深色友善列印樣式)。

風格:深夜藍黑漸層底、星金主色、思源宋體、宮格 hover 鎏金描邊微光、標題鎏金光暈。RWD 支援手機(窄螢幕十二宮格可捲動 / 縮放)。

## 8. 錯誤處理

| 情況 | 處理 |
|---|---|
| 表單未填完 / 日期超出 1900–2100 | 起盤前擋下,欄位旁紅字提示 |
| 農曆日期不存在 | 換算時偵測,提示重選 |
| 無金鑰 / 金鑰錯誤(401) | 顯示金鑰欄,訊息「金鑰無效,請重新輸入」 |
| 額度超限(429)/ 網路失敗 | 該面板顯示「重新揭示」,其餘保留 |
| 回應截斷 / 空白 | 視為該段失敗,可重生 |
| 本地排盤例外 | 全域捕捉,顯示友善錯誤,不出現白畫面 |

## 9. 測試

- **本地計算引擎**:確定性,以權威排盤工具預先算出標準答案,挑邊界案例(立春前後、節氣交界、子時換日、閏月、平閏年)寫測試案例核對四柱、命宮、五行局、紫微落宮、稱骨錢數。內嵌簡易測試頁 / console 測試函式,不引入框架。
- **Gemini 段落**:生成式內容無法斷言文字,只驗證呼叫成功、串流有資料、事實鎖定區正確帶入盤面。
- **UI**:手動在瀏覽器走黃金路徑與邊界(缺金鑰、超範圍日期、某段 API 失敗重生)。

## 10. 驗收標準

1. 雙擊 `ziwei-destiny.html` 即可在瀏覽器使用,無需安裝。
2. 輸入合法出生資料後,十二宮命盤於本地瞬間正確產出。
3. 八字四柱與稱骨重量正確,通過邊界測試案例。
4. 四段 Gemini 解讀依序串流顯示;任一段失敗可單獨重生。
5. 2026 流年面板正確顯示分項論斷。
6. 畫面呈現星空墨韻風格,支援手機;可列印 / 存 PDF;可另起一盤。
7. 頁尾顯示免責聲明。
